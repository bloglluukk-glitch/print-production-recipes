## 공개하는 내용

대용량 Illustrator 정리, 다종 양면 리플렛 분리, 납품 전 점검의 세 가지 실무 레시피를 한·영으로 제공합니다. 함께 제공하는 Illustrator 도구는 언어·작업·묶음 크기·도련을 고르는 실제 대화창입니다. 내려받아 Illustrator의 File → Scripts → Other Script로 실행합니다. Python과 터미널은 필요하지 않습니다. 브라우저에서 여는 `START_HERE.html`은 안내서입니다.

도구에는 자작 20종 더미 생성, 원본을 보존하는 AI 사본 축소, PDF 묶음 분리, 조건을 만족하는 독립 그룹의 AI/PDF 묶음 분리가 있습니다. 새 작업 폴더와 원본 바이트 사본을 남기며 기존 결과를 덮어쓰지 않습니다. 고객 디자인을 포함하거나 웹에서 인쇄 파일을 전송하지 않습니다.

## 실제 검증

Windows의 Illustrator **30.5.1**에서 직접 만든 CMYK A5 양면 리플렛 20종·40면을 생성해 시험했습니다. 개발용 구조·거부 조건 검사 **20/20** 통과. 실제 축소 AI는 40면과 그룹 40개를 유지한 채 다시 열렸습니다. AI 네 묶음도 각각 10면·10그룹, 원본 번호와 앞뒤 순서를 유지한 채 다시 열렸습니다.

축소본 40면, AI 분리 PDF 40면, PDF 전용 분리 40면을 원본 검토 PDF와 비교했습니다. **120회 렌더 비교에서 최대 평균 채널 차이 0.0**, 72ppi 조건입니다. 실제 도련 네 모서리를 모든 면에서 확인했고(160개 위치), 세 작업 폴더의 원본 사본 해시는 마스터와 일치했습니다. 대응표 20행도 검사했습니다.

자작 더미의 AI 파일은 **1,348,935 → 1,308,995바이트, 2.96% 감소**했습니다. 양쪽 압축을 켜고 PDF 호환만 달리했으며 이미지 변환은 하지 않았습니다. 단순 더미의 작은 측정이며 대용량 파일 성능을 대표하지 않습니다. 과거 약 1.93GB→184MB 기록은 별개의 고객 비공개 작업에 대한 크기 관찰로, 이 도구의 성능으로 표현하지 않습니다.

한·영 ScriptUI 구성과 언어 전환은 Illustrator에서 창 표시 없이 검사했습니다. 사람이 실제 버튼을 누르는 대화창 사용성 시험은 아직 하지 않았습니다. [전체 검증 기록](VALIDATION.json)

## 발견한 문제와 처리

테스트 환경에서 PDF 도련 옵션을 지정해도 실제 출력은 재단 크기만 포함했습니다. 설정값만 믿지 않고 결과 박스를 검사하여 발견했습니다. 현재 도구는 사본 아트보드를 일시적으로 확장해 바깥 실제 그림까지 검토 PDF에 포함합니다. 원본 AI와 저장된 분리 AI의 재단 아트보드는 A5를 유지합니다.

검토 PDF의 페이지는 A5+사방 3mm = **154×216mm**이며 별도 A5 재단 TrimBox는 없습니다. 인쇄소 최종 PDF는 원본 AI에서 도련·PDF/X·프로파일·마크를 설정해 따로 만듭니다. 도련을 포함한 출력 범위가 다른 면과 겹치면 자동 분리를 중단합니다.

## 지원 경계

전체 원본은 01부터 이어지는 LF-번호-FRONT/BACK 순서가 필요합니다. AI 분리는 ARTWORK 레이어 하나와 면별 독립 그룹, 지정 도련 경계 내의 그림만 지원합니다. 연결 이미지·여러 레이어·공유 그룹·숨긴 그룹 등은 수동 레시피로 정리합니다. 이 도구는 레이아웃 의미를 추측하거나 조판·양면 뒤집기를 자동 해결하지 않습니다.

선택적 JPEG/래스터 교체는 수동 레시피이며 자동 기능으로 검증하지 않았습니다. 실물 출력 교정은 **0회**입니다. PDF/X 인증, 물리 인쇄 품질, 색상 일치, 다른 Illustrator 버전, macOS의 실행은 미검증입니다.

## 공개 전 개인정보·권리 검수

고객 원본 AI·디자인·실명·고객 파일명·개인 PC 경로·내부 작업 대화·폰트 원본 파일·인증정보를 제외했습니다. 공개 PDF는 직접 만든 더미만 사용하고 작성자·제작자·XMP 메타데이터를 제거했습니다. 네이티브 AI 바이너리는 공개하지 않으며 사용자가 도구로 직접 생성합니다. PNG에는 별도 숨은 메타데이터를 넣지 않았습니다.
