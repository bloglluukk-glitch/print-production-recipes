# 빠른 시작 — 어떤 화면이 뜨는가

**한국어** | [English](QUICK_START.en.md)

Illustrator의 File → Scripts → Other Script에서 `scripts/Print_Recipes.jsx`를 실행하면 **인쇄물 정리 레시피** 대화창이 뜹니다. Python·Node·터미널을 사용할 필요가 없습니다. JSX를 파일 탐색기에서 더블클릭하는 방식은 권장 실행 경로가 아닙니다.

화면에는 **언어, 할 작업, 한 파일의 종류 수, 도련(mm), 실행, 닫기**가 있습니다. English를 선택하면 항목과 작업 안내가 영어로 바뀝니다. 일반 오류는 한·영을 함께 표시합니다.

1. **더미 리플렛 20종 만들기** → 저장 위치 선택 → `dummy-master.ai`가 새 폴더에 생기고 Illustrator에서 열립니다.
2. 같은 창에서 **편집용 AI 사본 축소** → 위치 선택 → 별도의 `print-job-…` 폴더에 원본 사본·축소 AI·보고서가 생깁니다. 이미지가 자동 변환되는 기능은 없습니다.
3. 원본 더미를 활성화한 상태에서 **독립 그룹 AI + PDF 묶음 분리**, 종류 수 **5**, 도련 **3** → 새 폴더에 AI 4개·PDF 4개·앞뒤 대응표·원본 사본·보고서가 생깁니다.
4. PDF만 필요하면 **양면 리플렛 PDF 묶음 분리**를 고릅니다.
5. 결과 AI를 다시 열고 원본과 PDF를 비교합니다. 재단 영역의 내용과 도련의 배경, 앞뒤 ID와 방향을 각각 확인합니다.

취소하면 실행하지 않습니다. 기존 결과를 덮어쓰지 않으며 오류가 나면 부분 결과도 남겨 확인할 수 있습니다. 묶음 파일의 앞뒤 순서는 인쇄기의 뒤집기·좌우 배치 설정을 대신하지 않습니다. 반환된 분리 AI는 원본 번호를 유지합니다; 자동 도구에 다시 넣을 때는 전체 원본의 순서 계약부터 확인하세요.

`examples/pair-map.csv`와 `examples/dummy-master.pdf`로 그림과 순서를 먼저 볼 수 있습니다. 실제 내 파일에 적용하려면 [분리 레시피](../recipes/02_SPLIT_LEAFLETS.md)의 구조를 맞추세요.

[소개](../README.md) · [출력 점검](../recipes/03_PREFLIGHT.md)

도구 PDF는 실제 바깥 도련을 포함한 검토 캔버스입니다. A5+3mm 예제의 페이지 크기는 154×216mm이며, 별도의 A5 재단 TrimBox는 지정하지 않습니다. 최종 인쇄 PDF는 원본 AI에서 인쇄소 설정으로 따로 만드세요.
