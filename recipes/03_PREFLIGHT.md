# 03 — 납품 전 점검표

**한국어** | [English](03_PREFLIGHT.en.md)

- [ ] 원본·편집 사본·최종 PDF가 구분되고 되돌릴 원본이 보존돼 있다.
- [ ] 종류 수와 면 수가 맞고 앞뒤 ID·내용·방향이 대응한다.
- [ ] 규격과 PDF의 TrimBox가 맞으며 BleedBox뿐 아니라 실제 그림이 도련 끝까지 이어진다.
- [ ] 글자·작은 선·QR·로고의 모양과 유효 이미지 해상도가 적합하다.
- [ ] 색상 프로파일·별색·오버프린트·투명도·폰트·링크를 인쇄소 조건에 맞춰 확인했다.
- [ ] 최종 PDF/X·압축·색상 변환·마크는 인쇄소 요구대로 설정했다. 도구의 검토 PDF는 이 확인을 대신하지 않는다.
- [ ] 원하지 않는 상단 파일명·날짜 표시는 PDF의 Page Information을 확인했다. 필요한 재단선은 따로 판단했다. [Adobe PDF 옵션](https://helpx.adobe.com/illustrator/using/pdf-options.html)
- [ ] AI 재열기, PDF 페이지 수, 대응표, 대표 장면을 넘어 전체 면 비교를 마쳤다.
- [ ] 긴쪽/짧은쪽 뒤집기, 조판, 접지·후가공 방향은 출력 업체와 확인했다.
- [ ] 공개 공유 시 고객 디자인·이름·주소·연락처·견적·PC 경로·PDF 메타데이터·이미지 숨은 정보가 제외됐다.

도련 설정과 실제 도련 그림은 다릅니다. 인쇄소의 도련 치수를 따르며, 예제의 3mm를 보편 규칙으로 사용하지 않습니다. [Adobe 도련 배경](https://helpx.adobe.com/illustrator/using/printers-marks-bleeds.html)

이 체크리스트는 작업 보조입니다. 디지털 면 비교가 물리 인쇄 교정·제본·색상 일치를 증명하지 않습니다.

[소개](../README.md)

도구 PDF는 실제 바깥 도련을 포함한 검토 캔버스입니다. A5+3mm 예제의 페이지 크기는 154×216mm이며, 별도의 A5 재단 TrimBox는 지정하지 않습니다. 최종 인쇄 PDF는 원본 AI에서 인쇄소 설정으로 따로 만드세요.
