# 02 — 다종 양면 리플렛 분리

**한국어** | [English](02_SPLIT_LEAFLETS.en.md)

## 먼저 면 대응을 확정하기

“20종”은 양면이라면 40면입니다. 파일 이름보다 먼저 각 종류의 앞·뒤·위쪽 방향을 대응표로 확정합니다. 앞면 20장 뒤에 뒷면 20장이 있는 문서를 연속 두 면씩 묶으면 잘못 짝지어집니다. 미리 **01 앞, 01 뒤, 02 앞, 02 뒤…**로 확인하고 정리합니다.

`examples/pair-map.csv`는 20종·40면 → 5종·10면 × 4개 예제입니다. 양면 인쇄기의 긴쪽/짧은쪽 뒤집기와 조판은 별도 확인 사항입니다.

## 자동 도구에 넣을 구조

1. 전체 원본은 `LF-01-FRONT`, `LF-01-BACK`, `LF-02-FRONT`, `LF-02-BACK` 순서로 이름을 지정합니다. 처음부터 01이며 번호가 이어져야 합니다. 자동 도구가 제목이나 디자인을 보고 앞뒤를 추측하지 않습니다.
2. PDF만 분리할 때는 위 이름과 순서를 맞추면 됩니다. 다른 아트보드에 걸친 그림·클리핑·레이어 상태는 사람이 별도로 확인합니다.
3. **네이티브 AI까지 분리할 때:** `ARTWORK` 레이어 하나에 면별 최상위 그룹 하나씩 만들고 그룹 이름을 해당 아트보드와 같게 합니다. 모든 실제 그림은 해당 면의 지정 도련 경계 안에 들어와야 합니다. 공유 배경은 필요한 면마다 독립적으로 보존합니다. 안내선은 도구 투입 사본에서 제외합니다.
4. 구조가 다른 원본은 사본에서 정리하거나 수동 분리를 사용합니다. 도구는 숨긴 그룹·잠긴 레이어·다른 면까지 걸친 그룹을 조용히 잘라내지 않고 중단합니다. 연결 이미지도 지원 범위 밖입니다.

## 분리와 확인

원본을 저장한 후 `scripts/Print_Recipes.jsx`에서 작업·묶음 크기·도련을 고릅니다. 새 폴더에 원본 사본, 범위별 AI/PDF, 대응표, 보고서가 생깁니다. 기존 파일은 덮어쓰지 않습니다. 20종을 6종씩 묶으면 6·6·6·2종으로 마지막 짝도 유지합니다.

AI 분리 시 아트보드와 해당 그룹만 남깁니다. **아트보드를 삭제했다고 다른 종류의 그림까지 삭제되는 것은 아니므로**, 결과 AI의 그룹 수와 PDF 내용도 확인합니다. 저장 직전 이름·면 순서를 검사하며, 분리된 AI는 전체 원본의 번호를 유지합니다.

한 종류의 앞뒤를 먼저 확인한 뒤 전체로 확장합니다. 각 묶음에서 10면·5종, 전체에서 40면·20종을 대조합니다. 파일을 다시 열어 글자, 실제 도련, 방향, 분리 경계가 맞는지 봅니다. 인쇄소에서 요청한 최종 PDF는 별도 설정으로 만듭니다.
