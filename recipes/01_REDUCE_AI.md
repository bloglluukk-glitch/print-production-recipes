# 01 — 대용량 Illustrator 파일 정리

**한국어** | [English](01_REDUCE_AI.en.md)

## 사용할 때

여러 아트보드와 무거운 포스터·이미지 때문에 편집·저장이 느릴 때. 먼저 편집성, 화질, 전달 호환성 중 무엇을 유지해야 하는지 정합니다. 작은 파일과 적합한 인쇄물은 같은 조건이 아닙니다.

## 작업 순서

1. 원본 AI를 보존하고 파일 크기, 아트보드 수, 링크·폰트 상태를 기록합니다. 원본·편집용 사본·출력 PDF의 이름을 구분합니다.
2. 문서 전체를 이미지로 바꾸지 말고 실제로 무거운 포스터/이미지 구간을 찾습니다. 해당 구간의 원본 그림과 배치 좌표·크기·클리핑·도련 범위를 별도로 기록합니다.
3. **이미지 변환이 필요하다면 수동으로:** 해당 구간만 사본에서 렌더/래스터화하고 실사용 크기와 인쇄소가 요청한 유효 해상도·색상 프로파일로 확인합니다. JPEG는 손실 압축이며 투명도를 유지하지 못합니다. 작은 글자·선·QR·로고는 벡터로 유지할지 따로 판단합니다. 이 도구는 이미지 변환을 실행하지 않습니다.
4. 교체는 기록한 좌표와 크기에서 수행합니다. 도련은 실제 그림이 재단선 밖까지 이어져야 합니다. 설정값만 늘리거나 가장자리를 복제했다고 적합한 그림이 자동 생기지 않습니다. 100% 확대 비교와 필요시 실제 출력 교정으로 확인합니다.
5. 내장 자산만 있는 저장된 AI라면 도구의 **편집용 AI 사본 축소**를 실행합니다. PDF 호환을 끈 파일은 Illustrator 편집용으로 구분하고 다른 앱에서의 미리보기·배치 필요성을 별도로 확인합니다. [Adobe의 저장 옵션 설명](https://helpx.adobe.com/illustrator/kb/optimize-native-pdf-file-sizes.html)
6. 인쇄용 PDF는 별도 사본에서 인쇄소 설정으로 만듭니다. PDF 편집 정보를 줄이는 것과 편집 원본을 보존하는 것을 구분합니다. 연결 이미지는 [Package](https://helpx.adobe.com/illustrator/using/package-files.html)로 함께 보존하고 재열기 시험을 합니다.
7. 전후 파일 크기만 비교하지 말고 아트보드·색·텍스트·도련·해상도·편집성도 비교합니다. 변경 원인과 되돌릴 원본을 남깁니다.

## 실패와 복구

- 교체 뒤 확대하면 흐림: 배치 후 유효 해상도와 원본 렌더 범위를 확인하고 원본으로 되돌립니다.
- 도련에 흰 틈/늘어난 그림: 실제 그림의 외곽과 클리핑을 고칩니다. 무리한 미러링으로 넘기지 않습니다.
- 다른 앱에서 AI 미리보기 불가: PDF 호환 사본 또는 별도 PDF를 용도에 맞춰 제공합니다.
- 링크를 빠뜨림: 자산을 패키지로 묶고 수신자 환경에서 다시 엽니다.

## 관찰과 검증의 범위

과거 개인 작업에는 약 1.93GB → 184MB의 파일 크기 변화가 기록됐지만 여러 작업이 함께 수행됐습니다. 특정 옵션 하나의 성능으로 일반화하지 않습니다. 공개판의 실제 측정은 자작 더미에 한정하여 [검증 기록](../docs/VALIDATION.json)에 따로 남깁니다. 대용량 성능, JPEG 교체 품질, 실물 인쇄는 이 공개 더미 검사로 증명하지 않습니다.
