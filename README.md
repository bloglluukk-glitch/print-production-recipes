# 인쇄물 정리 레시피

**한국어** | [English](README.en.md)

**큰 Illustrator 파일을 가볍게 정리하고, 여러 종류의 양면 리플렛을 앞뒤가 맞게 나누는 실무 노하우.**

이 저장소는 한·영 레시피, 체크리스트, 직접 만든 20종·40면 더미, **Illustrator 안에서 실행하는 한·영 도구 화면**을 제공합니다. 학습 데이터나 웹앱이 아닙니다. Illustrator가 필요하며 터미널이나 Python 설치 없이 사용할 수 있습니다.

## 먼저 실행하기

1. [배포 ZIP](https://github.com/bloglluukk-glitch/print-production-recipes/releases) 또는 GitHub의 Code → Download ZIP을 내려받아 압축을 풉니다.
2. Illustrator에서 **파일 → 스크립트 → 기타 스크립트 / File → Scripts → Other Script**로 `scripts/Print_Recipes.jsx`를 선택합니다. `scripts/lib`도 함께 있어야 합니다.
3. 언어를 고르고 **더미 리플렛 20종 만들기**를 실행합니다. 새 AI가 열립니다.
4. 같은 도구를 다시 실행하여 **편집용 AI 사본 축소** 또는 **독립 그룹 AI + PDF 묶음 분리**를 선택합니다. 기본값 5종이면 앞뒤 10면씩 네 묶음이 만들어집니다.

[빠른 시작과 실제 화면 동작](docs/QUICK_START.md) · 압축을 푼 후 `START_HERE.html`을 브라우저에서 열어도 한·영 안내를 읽을 수 있습니다. HTML은 안내서이며 Illustrator 작업을 실행하지 않습니다.

## 도구가 하는 일

- **AI 사본 축소:** 압축을 켜고 PDF 호환을 끈 새 편집용 AI를 저장합니다. 원본을 덮어쓰거나 자동으로 이미지를 저해상도로 바꾸지 않습니다.
- **PDF 묶음 분리:** 이름과 순서가 확인된 앞뒤 아트보드를 지정한 종류 수대로 검토용 PDF로 저장합니다.
- **독립 그룹 AI 분리:** 조건을 만족하는 면별 그룹만 유지한 AI와 검토용 PDF를 함께 저장합니다. 아트보드만 지우고 다른 종류의 그림이 남는 실수를 피합니다.
- 새 작업 폴더에 원본의 바이트 사본과 `pair-map.csv`를 남깁니다. 원본 문서는 변경·저장하지 않습니다.

자동 분리는 **LF-01-FRONT, LF-01-BACK, LF-02-FRONT, LF-02-BACK…** 순서가 필요합니다. AI 분리는 `ARTWORK` 레이어 하나, 아트보드와 같은 이름의 독립 그룹 하나씩, 지정 도련 안에 들어오는 그림만 지원합니다. 연결 이미지가 있는 파일은 먼저 패키지로 보존하고 수동 레시피를 사용하세요. 전체 인쇄물에 통용되는 자동 분리기는 아닙니다.

## 근거와 검증

개인 실무 기록에는 약 1.93GB의 AI가 이미지 처리 등 여러 변경 후 약 184MB가 된 사례가 있습니다. 이것은 과거 한 사례의 파일 크기 관찰이며, 이 도구의 재현 결과나 보장된 감소율이 아닙니다. 고객 원본·이름·경로는 포함하지 않습니다.

실제 Illustrator 30.5.1에서 더미 실행, 구조 검사 20개, 전체 면 렌더 비교 120회가 통과했습니다. 작은 더미의 축소량은 2.96%였으며 대용량 성능이나 실물 인쇄 검증은 아닙니다.
